`agent://<id>`: latest completed output (status + progress while unpublished); nested IDs dotted, `/key/index` JSON path; write = message, `agent://all` broadcast only.
Final replies: write `agent://<id>?replyTo=<incoming-message-id>` to fulfill that request. Interim acknowledgements/progress omit `replyTo`, neither fulfill it nor create a reverse reply obligation; the requester's later `wait` may still block for up to 30 minutes. A new question is tracked only when its sender owes that recipient no reply.
